# Hà Nội Xưa

A buildless Vietnamese heritage-tour landing page made with HTML, CSS and JavaScript. The page presents seven stops through a cinematic opening, an 1891 Hanoi map, editorial photo chapters and three interactive vector architecture models.

## Preview

From this directory, run: python -m http.server 4173 --directory dist

The finished static site is copied to dist/. Open http://localhost:4173 in a browser.

## Visual direction

- Ink green, aged ivory, lamp gold and lacquer red
- Fraunces display type with Be Vietnam Pro body copy
- Film grain, layered mist, old-map route and scroll-led story sequence
- Reduced-motion support, keyboard-accessible navigation and model tabs

## Asset notes

The hero still is a newly generated illustration. Location photography and the 1891 map are credited with links and license details in the page footer. Images used in the site are cropped and color-treated in the presentation.

The vector architecture models are illustrative, based on the cited photographs, research drawings and official references. They are not survey drawings or dimensionally accurate reconstructions.
